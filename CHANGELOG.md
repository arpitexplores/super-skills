# Changelog

## 2.2.0

- Adds a Git update preview that verifies the proposed release and lists workflow pin changes without touching the installed checkout or its Git refs.
- Brings exact release and workflow pin approvals into one request. Existing installation, integrity and rollback checks remain in place.

## 2.1.1

- Refreshes public documentation with clearer capability descriptions, installation guidance and workflow catalogue headings.
- Keeps public descriptions independent of workflow counts and separates product guidance from migration and compatibility information.
- No workflow, routing, updater or permission changes.

## 2.1.0

- Expands SEO and AI discovery evidence, workload capacity and recovery guidance, AI application and agent engineering, and security and asynchronous interface acceptance.
- Updates route intent, supporting references and optional specialist guidance. Retains 53 workflows and the existing public catalogue format.
- Reports observed checkout state and recovery references after an update or rollback failure. Preserves explicit approvals and installed-code validation.

## 2.0.0

- Replaces the active standalone collection with one Super Skills coordinator.
- Includes 53 complete workflows across 12 categories, with intent-based routing and supporting acceptance guidance.
- Adds package verification, offline guidance lookup, guarded updates and rollback.
- Documents installation and coexistence in Codex and Antigravity. Sampled compatibility tests passed with the limitations described in the README; full legacy parity is not claimed.
- Retains the MIT licence and preserves all 53 canonical workflow bodies.

## 1.0.0

- Initial public catalogue of standalone Super Skills.
- Included installation guidance, release documentation, issue templates and links to the individual skills.

Earlier versions remain available through the repository's history and release tags.
