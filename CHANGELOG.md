# Changelog

## 2.0.0

- Replaces the active standalone collection with one Super Skills coordinator.
- Includes 53 complete workflows across 12 categories, with intent-based routing and supporting acceptance guidance.
- Adds package verification, offline guidance lookup, guarded updates and rollback.
- Documents installation and coexistence in Codex and Antigravity. Sampled compatibility tests passed with the limitations described in the README; full legacy parity is not claimed.
- Retains the MIT licence and preserves all 53 canonical workflow bodies.

## 1.0.0

- Initial public catalogue of standalone Super Skills.
- Included installation guidance, release documentation, issue templates and links to the individual skills.

Earlier versions remain available through the repository's history and release tags.
